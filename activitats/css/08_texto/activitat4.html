Disseny Tipogràfic

En aquest exercici hem separat la jerarquia visual utilitzant dues fonts diferents carregades mitjançant @font-face. La font del títol aporta caràcter i elegància, mentre que la font del cos està optimitzada per a una lectura clara.

L'ús de variables CSS ens permet que, si en un futur decidim canviar la font Roboto per una altra, només hàgim de modificar una línia al :root i tota la web s'actualitzarà automàticament.
